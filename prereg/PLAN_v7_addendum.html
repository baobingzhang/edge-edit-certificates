E8：度收缩聚合 ShrinkGAM（主实验，预注册）

项目设定
模型logiti = b + S0i + (Σj∈N(i) S1j) / (|N(i)| + κ)，κ ≥ 0。κ=0 即 CertGAM。κ 相当于向 0 的先验伪计数：度越低，邻居项被压得越多。对参数仍是线性的，所以认证训练仍是凸的。
证书对固定的删除数 p 和插入数 q，分母 |N(i)|−p+q+κ 固定，所以"删最大的 p 个、加最小的 q 个"仍然是精确最坏情形，排序证书对任意 κ 都精确。实现放在新文件 code/shrink.py，不改动已冻结的 cert.py。
闸门 G9（正确性）(a) 在随机小图上穷举所有不超过 b 条的关联边编辑（b≤2，κ∈{0, 0.5, 3}），证书半径与穷举结果完全一致；(b) κ=0 时，在 Cora 和 Texas 上与 cert.radii 逐点一致；(c) 认证训练目标中的最坏集合与穷举一致。任一不通过则停下修复，不跑 E8。
训练与选择每个数据集沿用 S02 为 CertGAM-R 选定的配置（K, θ, λ, B, lr, solver）。只额外选 κ ∈ {0, 0.5, 1, 2, 4, 8, 16}，依据划分 0 的验证集（最多 1000 个节点）上的 0.5·clean + 0.5·cert1，与 CertGAM-R 的选择准则相同；平分时取较小的 κ。
评估与 S03 相同：划分 3–9，每个划分最多 2000 个测试节点，预算 {1,2,3,5,10}，精确证书，并保留随机编辑和对抗方向的独立重算检查。另以同一流程重跑 κ=0 作为配对基线，并记录每个节点的度，用于分层。
数据集主表的 11 个数据集。

理论（写入论文，作为命题）

  • 命题 2（精确性）：任意 κ≥0，上述排序证书精确。
  • 命题 3（单边灵敏度）：若 |S1jy−S1jc| ≤ R，则一条边编辑使间隔改变至多 2R/(d+κ−1)（删边，d+κ>1）或 2R/(d+κ+1)（加边）。κ 把低度节点的最坏灵敏度从 O(1) 降到 O(1/κ)。
